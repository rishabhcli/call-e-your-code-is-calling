## Deliberately not installed

- `@call-e/calle@0.6.0`: the official npm artifact has no declared licence or LICENSE file. ADR-0002 selects the documented REST API until clarified.
- `pg-native`: no measured need; it would add libpq/compiler/deployment variance.
- Broad OpenTelemetry `sdk-node` and auto-instrumentation bundles: Tier 6 will select explicit instrumentation after an overhead and privacy budget is defined.
